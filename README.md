# Ludo Telegram Mini App (Cloudflare)

Шашка ботының Cloudflare негізі (Worker + Durable Object) сақталды, ойын толық Лудоға ауыстырылды.

## Орнату
1. `wrangler.toml` ішіндегі `BOT_USERNAME` (@-сыз), `WEBHOOK_URL`, `MINI_APP_URL` мәндерін өз ботыңа сәйкестендір.
2. `npx wrangler secret put BOT_TOKEN`
3. Сынақ режимін өшір: `DEV` және `SKIP_WEBHOOK` жолдарын `wrangler.toml` ішінен алып таста.
4. `npm install && npx wrangler deploy` — webhook автоматты орнатылады.
5. BotFather → Bot Settings → Configure Mini App (Main Mini App) → `MINI_APP_URL` сілтемесін қой.
   Доспен ойнау шақыру сілтемесі (`t.me/БОТ?startapp=room_КОД`) осы баптауға байланысты.

## Сынақ (Telegram-сыз)
`DEV = "1"` кезінде браузерде `https://.../?dev=Ali` ашсаң болады (әр қойындыға басқа ат).

## Ережелер
- 6 шықса фишка үйден шығады; 6 / жеп алу / финишке жету — қосымша лақтыру; қатарынан 3 алты — кезек өтеді.
- Бастапқы ұяшықтар мен ☆ ұяшықтарында фишканы жеуге болмайды. Финишке дәл сан керек.
- Бірінші болып 4 фишкасын финишке жеткізген жеңеді.
- Кездейсоқ ойын: 20 секунд іздеу, 4 адам толса бірден басталады, 2-ден аз болса іздеу жалғасады.
- Доспен ойын: бөлме жасаушы ғана «Бастау» басады (кемі 2 адам болғанда көрінеді).
- Бір әрекетке 25 секунд; 3 рет өткізсе немесе байланыс үзілсе, ойынды автомат жалғастырады.
